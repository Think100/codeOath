Adding another post is simple: create a new `.md` file in the `posts/` folder,
give it a title and a date, and refresh the page. No restart needed.

Because this post has a later date than the welcome post, it appears **first**
on the index page.

## A few tips

- Keep slugs short and lowercase (the file name is the URL)
- Leave `tags` out entirely if a post does not need any
- Use a future date if you want a post to sort to the top
