This is your first post. It lives as a plain Markdown file in the `posts/`
folder. The file name, `welcome.md`, becomes the URL slug: `/post/welcome`.

## Writing posts

Every post starts with a small header (called *front matter*) between two
`---` lines:

- `title` shows up as the heading and in the post list
- `date` uses the format `YYYY-MM-DD` and controls the order (newest first)
- `tags` are optional and comma-separated

## Markdown you can use

You can write **bold text**, *italic text*, and `inline code`. Links look
like [this](https://example.com). Lists work too:

1. First
2. Second
3. Third

> Blockquotes are handy for asides.

```python
print("code blocks keep their formatting")
```

That is everything you need to start writing.
