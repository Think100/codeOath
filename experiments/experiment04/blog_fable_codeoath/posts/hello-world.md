Welcome to the blog. Every post is a plain Markdown file in the `posts/`
folder. The filename becomes the URL: this one is `hello-world.md`, so it
lives at `/posts/hello-world`.

## How a post looks

Each file starts with a small metadata block:

```yaml
---
title: Hello, world
date: 2026-06-28
tags: [meta]        # optional
---
```

Everything after the second `---` is regular Markdown.
