Markdown keeps the writing close to plain text while still supporting the
formatting a blog needs.

## The essentials

- *Emphasis* and **strong emphasis**
- [Links](https://daringfireball.net/projects/markdown/)
- Inline `code` and fenced code blocks

> Blockquotes work too, for the occasional borrowed thought.

| Element | Syntax |
| ------- | ------ |
| Heading | `## Title` |
| List    | `- item` |

Tables and fenced code blocks are enabled through Markdown extensions.
