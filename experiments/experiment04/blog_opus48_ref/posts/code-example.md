Fenced code blocks are supported with syntax highlighting. Here is a small
Python snippet:

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"


print(greet("world"))
```

Inline code such as `print()` works too, and tables render nicely:

| Feature   | Supported |
| --------- | --------- |
| Headings  | Yes       |
| Tables    | Yes       |
| Code      | Yes       |
